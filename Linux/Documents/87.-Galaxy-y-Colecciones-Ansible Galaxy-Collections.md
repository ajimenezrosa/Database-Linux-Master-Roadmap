# ¿Qué es Ansible Galaxy?

Ansible Galaxy es el repositorio oficial de contenido reutilizable para Ansible.

Permite descargar:

- Roles
- Collections
- Plugins
- Módulos
- Documentación

Todo desarrollado por:

- Red Hat
- Fabricantes
- Comunidad Open Source
- Empresas

# ¿Qué es una Collection?

Una Collection es un paquete que agrupa múltiples componentes relacionados.

Puede contener:

- Roles
- Módulos
- Plugins
- Filtros
- Documentación
- Playbooks
- Ejemplos

---

# Evolución de Ansible

Antes.

```text
Playbook

↓

Role

↓

Servidor
```

---

Ahora.

```text
Playbook

↓

Collection

↓

Roles

↓

Módulos

↓

Plugins

↓

Servidor
```

---

# Diferencia entre Role y Collection

| Role | Collection |
|-------|------------|
| Automatiza una tarea | Agrupa múltiples componentes |
| Generalmente un único propósito | Varios propósitos relacionados |
| Puede incluir Tasks, Templates y Variables | Incluye Roles, Plugins, Módulos y mucho más |
| Más pequeño | Mucho más completo |

---

# Introducción

En la fase anterior aprendimos cómo instalar manualmente un Role.

Ejemplo.

```bash
ansible-galaxy role install geerlingguy.apache
```

Y una Collection.

```bash
ansible-galaxy collection install community.general
```

Pero imaginemos un proyecto empresarial que utiliza:

- 18 Roles
- 24 Collections

Instalarlos uno por uno sería lento y propenso a errores.

Para resolver este problema Ansible utiliza un archivo llamado:

```text
requirements.yml
```

---

# ¿Qué es requirements.yml?

Es un archivo YAML que define todas las dependencias del proyecto.

Puede incluir:

- Roles
- Collections
- Versiones específicas

Su objetivo es permitir que cualquier administrador pueda reconstruir el entorno con un solo comando.

---

# Arquitectura

```text
Proyecto

↓

requirements.yml

↓

Ansible Galaxy

↓

Descarga

↓

Proyecto listo
```

---

# Beneficios

- Automatización.
- Reproducibilidad.
- Versionado.
- Consistencia.
- Fácil mantenimiento.

---

# Archivo requirements.yml

Ejemplo sencillo.

```yaml
roles:

  - name: geerlingguy.apache

  - name: geerlingguy.mysql

collections:

  - name: community.general

  - name: community.postgresql
```

---

# Instalación

Una vez creado el archivo.

Ejecutamos.

```bash
ansible-galaxy install -r requirements.yml
```

---

```text

Galaxy

↓

Roles

↓

Collections

↓

Proyecto listo
```

```

```

```text
Version conflict
```

Dos componentes requieren versiones incompatibles.

## Error

```text

```

Generalmente.

```

```

- Collection.
- Role.
- Ansible.
