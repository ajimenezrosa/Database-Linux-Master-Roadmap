Linux es un sistema operativo de código abierto basado en Unix, diseñado para ser seguro, estable y altamente configurable. Es ampliamente utilizado en servidores, dispositivos móviles, supercomputadoras y sistemas embebidos.

### 🔑 Características principales:

* Código abierto (Open Source)
* Multiusuario y multitarea
* Alta seguridad y estabilidad
* Compatible con múltiples arquitecturas
* Gran comunidad global

Aunque Linux está inspirado en Unix, existen diferencias importantes entre ambos.

### 🆚 Comparativa:

| Característica | Unix                    | Linux                           |
| -------------- | ----------------------- | ------------------------------- |
| Licencia       | Propietaria             | Código abierto                  |
| Costo          | Generalmente pago       | Gratis                          |
| Uso            | Corporativo tradicional | Amplio (personal y empresarial) |
| Desarrollo     | Centralizado            | Comunitario                     |
| Ejemplos       | AIX, HP-UX, Solaris     | Ubuntu, CentOS, Debian          |

### 🎯 Conclusión:

Linux democratizó el acceso a sistemas tipo Unix, permitiendo a cualquier persona aprender, modificar y desplegar soluciones a gran escala.
