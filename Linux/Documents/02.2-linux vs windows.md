# Linux vs Windows

![Administrador trabajando con Linux y Windows](images/04-linux-vs-windows-portada.jpg)

> **Objetivo de la lección**
>
> Comprender las principales diferencias entre Linux y Windows, conocer sus fortalezas, debilidades y aprender cuándo es recomendable utilizar cada uno.

---

# Introducción

Una de las preguntas más comunes durante una entrevista para un puesto relacionado con Linux, administración de sistemas, DevOps o infraestructura es:

> **¿Qué diferencias existen entre Linux y Windows?**

Incluso es frecuente escuchar preguntas como:

- ¿Cuál prefieres utilizar?
- ¿Por qué escogerías Linux sobre Windows?
- ¿En qué escenarios utilizarías cada sistema operativo?

No existe una respuesta única. Ambos sistemas operativos tienen ventajas y están diseñados para satisfacer necesidades diferentes.

Durante esta lección analizaremos sus diferencias más importantes desde el punto de vista de un administrador de sistemas.

---

# Comparación general

| Característica | Linux | Windows |
|---------------|--------|----------|
| Licencia | Principalmente software libre y de código abierto | Software propietario |
| Fabricante | Comunidad y múltiples empresas | Microsoft |
| Costo | Generalmente gratuito | Licencia comercial |
| Personalización | Muy alta | Limitada |
| Servidores | Muy utilizado | Utilizado principalmente con Windows Server |
| Escritorio | Muy utilizado | Dominante |
| Línea de comandos | Fundamental | Opcional |
| Seguridad | Muy alta | Alta |
| Distribuciones | Muchas | Versiones oficiales |
| Administración remota | SSH | RDP, PowerShell |

# 1. Código fuente

![Programador revisando código fuente](images/04-open-source.jpg)

## Linux

Linux es un sistema operativo **de código abierto**.

Esto significa que el código fuente puede:

- Estudiarse.
- Modificarse.
- Adaptarse.
- Compartirse.
- Mejorarse.

Miles de desarrolladores colaboran continuamente para mejorar Linux.

Gracias a ello existen numerosas distribuciones adaptadas a diferentes necesidades.

Por ejemplo:

- Servidores.
- Escritorio.
- Redes.
- Supercomputadoras.
- Dispositivos embebidos.

---

## Windows

Windows es un sistema operativo **propietario** desarrollado por Microsoft.

El usuario no tiene acceso al código fuente.

Esto implica que:

- No puede modificar el sistema operativo.
- Las mejoras dependen exclusivamente del fabricante.
- La personalización interna es limitada.

---

# 2. Costo

![Compra de licencia de software](images/04-licencias.jpg)

## Linux

La mayoría de las distribuciones pueden descargarse e instalarse sin costo.

Ejemplos:

- Fedora
- Debian
- Ubuntu
- Rocky Linux
- AlmaLinux

En el caso de **Red Hat Enterprise Linux**, el software puede obtenerse para fines de desarrollo y aprendizaje, mientras que las empresas pagan por:

- Soporte técnico.
- Actualizaciones certificadas.
- Acceso a repositorios empresariales.
- Asistencia oficial.

No se paga por "Linux", sino por los servicios asociados.

---

## Windows

Generalmente requiere una licencia comercial.

Muchas computadoras incluyen el costo de Windows dentro del precio del equipo.

Aunque el usuario no vea una factura independiente, la licencia normalmente ya fue pagada por el fabricante.

---

# 3. Interfaz de usuario

![Escritorio GNOME y Windows](images/04-escritorios-linux.jpg)

## Linux

Linux ofrece diferentes entornos gráficos.

Algunos de los más conocidos son:

- GNOME
- KDE Plasma
- XFCE
- Cinnamon
- MATE

Cada uno posee:

- Apariencia diferente.
- Herramientas distintas.
- Diferente consumo de recursos.

El usuario puede cambiar completamente el entorno gráfico sin reinstalar el sistema operativo.

En servidores empresariales normalmente **no existe interfaz gráfica**.

Toda la administración se realiza desde la terminal.

---

## Windows

Windows mantiene una interfaz gráfica relativamente uniforme entre sus versiones.

Está diseñada para que un usuario promedio pueda trabajar fácilmente mediante ventanas, iconos y menús.

Su nivel de personalización es considerablemente menor que Linux.

---

# 4. Línea de comandos

![Terminal Linux](images/04-terminal-linux.jpg)

Una de las mayores diferencias entre ambos sistemas es el uso de la terminal.

## Linux

La terminal es una herramienta fundamental.

Permite:

- Administrar servidores.
- Automatizar tareas.
- Ejecutar scripts.
- Configurar servicios.
- Solucionar problemas.
- Acceder remotamente mediante SSH.

Comandos comunes:

```bash
pwd
ls
cd
cp
mv
rm
systemctl
journalctl
dnf
find
grep
```

---

## Windows

Windows dispone de:

- Command Prompt (CMD)
- Windows PowerShell
- PowerShell 7

PowerShell es muy potente y actualmente puede realizar tareas avanzadas de administración.

Sin embargo, muchos usuarios continúan utilizando principalmente la interfaz gráfica.

---

# 5. Instalación de software

![Administrador instalando paquetes](images/04-paquetes-linux.jpg)

## Linux

La instalación normalmente se realiza mediante administradores de paquetes.

Ejemplos:

| Distribución | Administrador |
|--------------|---------------|
| Fedora | DNF |
| RHEL | DNF |
| Debian | APT |
| Ubuntu | APT |
| Arch Linux | pacman |

Ejemplo:

```bash
sudo dnf install nginx
```

o

```bash
sudo apt install nginx
```

El administrador descarga automáticamente:

- El paquete.
- Las dependencias.
- Las bibliotecas necesarias.

---

## Windows

Tradicionalmente la instalación se realiza mediante archivos:

- .exe
- .msi

El usuario debe:

1. Descargar el instalador.
2. Ejecutarlo.
3. Seguir el asistente.

Actualmente también existen gestores como:

- Microsoft Store
- winget

---

# 6. Seguridad

![Centro de operaciones de seguridad](images/04-seguridad.jpg)

Linux es reconocido por su sólido modelo de seguridad.

Entre sus mecanismos destacan:

- Usuarios.
- Grupos.
- Permisos.
- sudo
- SELinux.
- Firewalld.
- SSH.
- Registro de eventos.

Debido a su arquitectura y al modelo de permisos, Linux suele ser menos afectado por malware.

Sin embargo:

> **Ningún sistema operativo es completamente seguro.**

Una mala configuración puede comprometer tanto Linux como Windows.

---

## Windows

Windows ha mejorado enormemente su seguridad.

Actualmente incorpora:

- Windows Defender.
- BitLocker.
- Windows Firewall.
- Secure Boot.
- Credential Guard.

No obstante, debido a su enorme cantidad de usuarios, continúa siendo uno de los principales objetivos del malware.

---

# 7. Estabilidad y rendimiento

![Servidores Linux funcionando](images/04-servidores-estables.jpg)

Linux es conocido por su estabilidad.

Muchos servidores funcionan durante meses o incluso años sin reiniciarse, salvo cuando es necesario aplicar determinadas actualizaciones del kernel o realizar mantenimiento planificado.

Es ampliamente utilizado en:

- Bancos.
- Plataformas web.
- Cloud.
- Bases de datos.
- Supercomputadoras.

Además, Linux puede ejecutarse eficientemente tanto en hardware moderno como en equipos antiguos.

---

Windows también es estable y ha mejorado considerablemente durante los últimos años.

Sin embargo, suele requerir reinicios más frecuentes debido a:

- Actualizaciones.
- Instalación de controladores.
- Cambios importantes del sistema.

---

# 8. Sistemas de archivos

![Estructura de archivos Linux](images/04-filesystem.jpg)

## Linux

Entre los sistemas de archivos más utilizados se encuentran:

- ext4
- XFS
- Btrfs

Linux organiza todo a partir de un único directorio raíz:

```
/
```

Todo cuelga del directorio raíz.

Además, Linux considera prácticamente todo como un archivo, incluyendo muchos dispositivos del sistema.

Ejemplos:

```
/dev/sda
/dev/null
/dev/tty
```

---

## Windows

Los sistemas de archivos más comunes son:

- NTFS
- FAT32
- exFAT

Windows utiliza letras para identificar unidades:

```
C:
D:
E:
```

Cada unidad posee su propia estructura independiente.

# Linux y Windows en servidores

Actualmente Linux domina ampliamente el mercado de servidores.

Es utilizado para ejecutar:

- Servidores web.
- PostgreSQL.
- MySQL.
- Oracle.
- Kubernetes.
- Docker.
- Podman.
- Apache.
- Nginx.

Windows Server también es muy utilizado en:

- Active Directory.
- Exchange.
- IIS.
- Aplicaciones .NET.
- Infraestructura Microsoft.

# ¿Cuál debería elegir?

La respuesta depende del escenario.

### Linux

Ideal para:

- Servidores.
- Cloud.
- DevOps.
- Bases de datos.
- Automatización.
- Redes.
- Seguridad.
- Contenedores.

---

### Windows

Ideal para:

- Escritorio corporativo.
- Usuarios domésticos.
- Microsoft Office.
- Juegos.
- Aplicaciones comerciales.
- Software específico de Windows.

# Pregunta típica de entrevista

**¿Qué prefieres utilizar?**

Una buena respuesta podría ser:

> *Para administración de servidores prefiero Linux debido a su estabilidad, seguridad, automatización mediante línea de comandos y excelente integración con tecnologías como Docker, Kubernetes y plataformas de nube. Para aplicaciones específicas de Microsoft o software exclusivo de Windows, utilizaría Windows cuando sea la mejor opción para el negocio.*

---

# Resumen

Linux y Windows son excelentes sistemas operativos, pero fueron diseñados con enfoques diferentes.

Linux destaca por:

- Código abierto.
- Seguridad.
- Estabilidad.
- Automatización.
- Personalización.
- Servidores.

Windows destaca por:

- Facilidad de uso.
- Amplia compatibilidad con software comercial.
- Excelente integración con el ecosistema Microsoft.
- Gran adopción en escritorios.

Como administrador de sistemas, conocer ambos entornos te permitirá elegir la herramienta adecuada para cada situación.
