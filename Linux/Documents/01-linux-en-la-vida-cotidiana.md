# Linux en la vida cotidiana

![Linux en dispositivos de uso diario](https://commons.wikimedia.org/wiki/Special:FilePath/Linksys-Wireless-G-Router.jpg)

> **Objetivo de la lección:** reconocer cómo Linux está presente en numerosos dispositivos y servicios que utilizamos todos los días, incluso cuando no vemos directamente el sistema operativo.

---

## Introducción

Cuando pensamos en Linux, normalmente imaginamos una computadora, una terminal negra o un servidor administrado por especialistas. Sin embargo, Linux se encuentra mucho más cerca de nosotros de lo que parece.

Muchas tecnologías modernas utilizan el **kernel de Linux** o sistemas operativos construidos a partir de él. Esto ocurre porque Linux es flexible, estable, seguro y puede adaptarse a dispositivos con capacidades muy diferentes: desde pequeños routers domésticos hasta grandes plataformas de Internet.

En muchos casos, Linux funciona de manera silenciosa en segundo plano. El usuario no necesita abrir una terminal ni conocer comandos para beneficiarse de él.

---

## 1. Sistemas de entretenimiento en aviones

![Sistema de entretenimiento a bordo](https://commons.wikimedia.org/wiki/Special:FilePath/Video-System%20MD-11%20Swissair%20-%20ETHZ%20LBS%20SR04-030091.jpg)

Los sistemas de entretenimiento instalados en los asientos de algunos aviones pueden utilizar plataformas basadas en Linux.

Estos sistemas permiten:

- Reproducir películas y series.
- Mostrar información sobre el vuelo.
- Ejecutar mapas interactivos.
- Administrar música y juegos.
- Conectar los diferentes monitores con un servidor central.

Linux resulta adecuado para estos entornos porque puede configurarse para realizar una función específica durante largos períodos, con una interfaz sencilla para el pasajero.

> **Importante:** no todos los sistemas de entretenimiento aéreo utilizan Linux, pero Linux ha sido empleado en distintas plataformas de entretenimiento a bordo.

## 2. Routers y equipos de acceso a Internet

![Router inalámbrico](https://commons.wikimedia.org/wiki/Special:FilePath/Linksys-Wireless-G-Router.jpg)

El router que distribuye Internet dentro de una casa u oficina es, en esencia, una pequeña computadora especializada.

Muchos routers ejecutan sistemas embebidos basados en Linux para realizar tareas como:

- Asignar direcciones IP mediante DHCP.
- Administrar conexiones Wi-Fi.
- Aplicar reglas de firewall.
- Traducir direcciones mediante NAT.
- Mostrar una página web de administración.
- Controlar el tráfico entre la red local e Internet.

Cuando accedemos a una dirección como `192.168.1.1` para cambiar la contraseña del Wi-Fi, probablemente estamos utilizando una aplicación web servida por el propio router.

Algunos proyectos conocidos, como **OpenWrt**, permiten instalar una distribución Linux especializada en determinados routers compatibles.

## 3. Internet, servidores y motores de búsqueda

Cada vez que abrimos una página web, enviamos un correo electrónico o utilizamos un servicio en la nube, es muy probable que parte de la infraestructura involucrada utilice Linux.

Linux es ampliamente utilizado en:

- Servidores web.
- Centros de datos.
- Plataformas de computación en la nube.
- Sistemas de bases de datos.
- Contenedores.
- Plataformas de búsqueda.
- Servicios de transmisión de contenido.

Empresas tecnológicas de gran escala utilizan Linux porque puede administrarse de manera automatizada, soportar grandes cargas de trabajo y ejecutarse en una enorme variedad de hardware.

Esto significa que, aunque una persona utilice Windows, macOS o iOS, muchos de los servicios remotos a los que accede pueden estar funcionando sobre Linux.

## 4. Teléfonos inteligentes y tabletas

![Teléfono inteligente Android](https://commons.wikimedia.org/wiki/Special:FilePath/Updating%20Android%20smartphone%2020180929.jpg)

Android utiliza el kernel de Linux como una parte fundamental de su arquitectura.

Por eso, millones de teléfonos y tabletas incorporan tecnología Linux, aunque el usuario vea la interfaz de Android y no un escritorio tradicional como GNOME o KDE.

El kernel se encarga de tareas esenciales como:

- Administrar la memoria.
- Controlar los procesos.
- Comunicarse con el hardware.
- Gestionar la batería.
- Manejar dispositivos como la cámara, la pantalla y el almacenamiento.
- Aplicar mecanismos de seguridad.

Sin embargo, es importante comprender que **Android no es simplemente una distribución Linux de escritorio**. Tiene su propio entorno, bibliotecas, modelo de aplicaciones e interfaz de usuario.

---

## 5. Televisores inteligentes

Muchos televisores modernos incluyen un sistema operativo capaz de ejecutar aplicaciones, conectarse a Internet y reproducir contenido desde diferentes plataformas.

Diversos sistemas utilizados en televisores inteligentes se basan en Linux. Entre sus funciones se encuentran:

- Ejecutar aplicaciones de streaming.
- Administrar conexiones de red.
- Reproducir contenido multimedia.
- Reconocer dispositivos conectados por HDMI.
- Descargar actualizaciones.
- Integrarse con servicios domésticos inteligentes.

El televisor puede parecer un electrodoméstico tradicional, pero internamente funciona como una computadora especializada.

---

## 6. Lectores de libros electrónicos

Los lectores de libros electrónicos también pueden utilizar sistemas basados en Linux.

Linux permite administrar:

- La pantalla de tinta electrónica.
- La biblioteca digital.
- El almacenamiento interno.
- La conexión Wi-Fi.
- La sincronización de libros.
- El consumo eficiente de energía.

En este tipo de dispositivo, el sistema operativo está optimizado para ejecutar pocas funciones y conservar la batería durante largos períodos.

---

## 7. Discos de recuperación y herramientas de mantenimiento

Algunas herramientas creadas para reparar equipos con Windows se ejecutan desde un entorno Linux arrancable.

Por ejemplo, un medio de recuperación puede iniciar una distribución Linux ligera para:

- Copiar archivos de un disco dañado.
- Modificar particiones.
- Analizar sistemas de archivos.
- Restablecer configuraciones.
- Eliminar malware.
- Realizar copias de seguridad.
- Recuperar información antes de reinstalar Windows.

Esto demuestra que Linux también puede ser útil como plataforma de diagnóstico, incluso cuando el sistema instalado originalmente es otro.

---

## 8. Electrodomésticos inteligentes

Los electrodomésticos modernos incluyen cada vez más pantallas, sensores, conexión Wi-Fi y funciones automáticas.

Linux puede encontrarse en equipos como:

- Refrigeradores inteligentes.
- Sistemas de climatización.
- Cámaras de seguridad.
- Equipos multimedia.
- Dispositivos de automatización doméstica.
- Paneles de control industrial.
- Sistemas de vigilancia.

En estos casos suele utilizarse una versión reducida y personalizada, conocida como **Linux embebido**.

### ¿Qué es un sistema embebido?

Un sistema embebido es una computadora integrada dentro de otro dispositivo y diseñada para cumplir una función específica.

A diferencia de una computadora personal, normalmente:

- No permite instalar cualquier aplicación.
- Tiene recursos limitados.
- Ejecuta tareas predefinidas.
- Puede funcionar sin teclado ni ratón.
- Está integrado directamente en el producto.

## 9. Automóviles y conducción autónoma

![Vehículo de conducción autónoma](https://commons.wikimedia.org/wiki/Special:FilePath/Google%20self%20driving%20car%20at%20the%20Googleplex.jpg)

Los automóviles modernos incorporan múltiples computadoras para controlar sistemas de entretenimiento, navegación, sensores y asistencia al conductor.

Linux puede utilizarse en áreas como:

- Pantallas del vehículo.
- Sistemas de navegación.
- Entretenimiento.
- Comunicación entre módulos.
- Procesamiento de cámaras.
- Plataformas de prueba.
- Sistemas avanzados de asistencia al conductor.
- Investigación relacionada con vehículos autónomos.

Los vehículos de conducción autónoma necesitan procesar grandes cantidades de información proveniente de cámaras, radares, sensores y mapas. Linux es una plataforma habitual para desarrollar y probar este tipo de soluciones, aunque el sistema completo puede combinar diferentes tecnologías y sistemas operativos.

## 10. ¿Por qué Linux se utiliza en tantos dispositivos?

Linux ofrece varias ventajas importantes.

### Código abierto

Su código puede estudiarse, modificarse y adaptarse a necesidades específicas.

### Flexibilidad

Puede ejecutarse en servidores muy potentes, computadoras personales y pequeños dispositivos embebidos.

### Estabilidad

Es adecuado para sistemas que deben permanecer funcionando durante largos períodos.

### Seguridad

Incluye mecanismos de usuarios, permisos, aislamiento de procesos y control de acceso.

### Compatibilidad con diferentes arquitecturas

Linux puede adaptarse a procesadores como:

- x86_64
- ARM
- RISC-V
- PowerPC

### Comunidad y ecosistema

Existe una gran cantidad de herramientas, documentación, controladores y proyectos de código abierto disponibles.

## 11. Linux visible y Linux invisible

Podemos clasificar el uso de Linux en dos grandes grupos.

| Tipo de uso | Ejemplos |
|---|---|
| **Linux visible** | Red Hat Enterprise Linux, Fedora, Ubuntu, Debian y otras distribuciones instaladas en computadoras o servidores. |
| **Linux invisible** | Routers, televisores, teléfonos Android, sistemas de entretenimiento, electrodomésticos y dispositivos embebidos. |

En el primer caso, el usuario sabe que trabaja con Linux. En el segundo, Linux forma parte del producto, pero permanece oculto detrás de una interfaz gráfica simplificada.

Aunque un estudiante de RHCSA no administrará necesariamente televisores o sistemas de entretenimiento aéreo, estos ejemplos ayudan a comprender la importancia del ecosistema Linux.

- Procesos y servicios.
- Redes.
- Almacenamiento.
- Registros del sistema.
- Seguridad.

## Conclusión

Linux no se limita a servidores o computadoras de escritorio. Está presente en una gran variedad de dispositivos, servicios y plataformas que utilizamos diariamente.

Puede encontrarse en routers, teléfonos Android, televisores, lectores electrónicos, sistemas de recuperación, electrodomésticos, servicios de Internet y automóviles.

Comprender esta presencia permite valorar la importancia de Linux y explica por qué las habilidades de administración aprendidas durante la preparación de RHCSA tienen tanta relevancia en el mundo tecnológico.
